这个页面现在能做什么

目前它还是一个纯静态网页，不依赖数据库，也不需要后端程序。 你只要改 GitHub 仓库里的 index.html，提交后 Cloudflare 就会重新拉代码并部署。 这很适合先把主页和导航页搭起来，后面再慢慢加页面。
